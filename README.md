# Опросник

Простое full-stack веб-приложение для создания анкет, прохождения опросов и просмотра статистики.

## Запуск

```bash
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

## Возможности

- Создание анкет с вопросами и вариантами ответов.
- Прохождение опросов.
- Просмотр простой статистики по ответам.
- Временная JSON-база данных (`data/db.json`).
